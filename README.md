# CosyTales Productivity

A cozy productivity app built with React + Vite. Features a dashboard with a focus timer, to-do list, and daily quotes to keep you motivated.

## Features

- **Focus Timer** — Pomodoro-style countdown to stay on task
- **To-Do List** — Add and manage your daily tasks
- **Daily Quotes** — Inspirational quotes to brighten your session
- **Landing Page** — Clean entry point before the dashboard
